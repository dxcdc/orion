Prerequisites #

To get started with Lahomes, please follow the steps below to install and set up all the necessary prerequisites:

  • Python

    Make sure to have the Python installed & running in your computer. If you already have installed Python on your computer, you can skip this step.

    For windows

    • Download python from windows store
    • Select the Python's version to download
    • Click on the install

    For Linux

    • sudo apt update
    • sudo apt install python3

  • Virtualenv

    Make sure to have the virtualenv installed globally & running on your computer. If you already have installed on your computer, you can skip this step.

    Virtualenv installation command for linux & mac os
    python3 -m pip install --user virtualenv
    Virtualenv installation command for Windows
    py -m pip install --user virtualenv

Command Description

Prerequisites

To get started with Lahomes, please follow the steps below to install and set up all the necessary prerequisites:

  • Node.js

    To use our build tools and take full advantage of Lahomes's customization options, you will need to download and install Node.js. If you do not have Node.js installed already, you can download the package installer from the official website. We recommend that you download the stable version of Node.js (LTS) to ensure the best possible experience.

  • Gulp

    Ensure that you have Gulp installed and running on your computer. If you already have Gulp installed, you can skip this step. If not, you can install it by running the following command from your terminal: npm install -g gulp.

Installation

Run following commands in separate terminal.

You can run this app using any following package manager: Bun, Yarn or NPM

1. Bun

If you don't have bun installed on your PC, use the npm i -g bun or sudo npm i -g bun to install

Command Description
bun i
 This would install all required dependencies in node_modules folder.
bun dev Builds and minifies styles and scripts, initiates a watch process to detect files changes.
bun run build Builds the styles and scripts for production. Your app is now ready to be deployed.
2. Yarn

If you don't have yarn installed on your PC, use the next command npm i -g yarn or sudo npm i -g yarn

Command Description
yarn
 This would install all required dependencies in node_modules folder.
yarn dev Builds and minifies styles and scripts, initiates a watch process to detect files changes.
yarn build Builds the styles and scripts for production. Your app is now ready to be deployed.
3. NPM

npm comes preinstalled when you install Nodejs

Command Description
npm i or npm i --force
 This would install all required dependencies in node_modules folder.
npm run dev Builds and minifies styles and scripts, initiates a watch process to detect files changes.
npm run build Builds the styles and scripts for production. Your app is now ready to be deployed.
